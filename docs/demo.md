# Demo storyboard / 演示脚本 / デモ台本

The repository includes a clean web-studio screenshot, a data-safe product trailer, and an architecture diagram. A richer live screen recording is intentionally left to maintainers so it can be refreshed as the UI evolves without capturing local project data.

For a fresh 60–90 second recording, use this storyboard:

1. **00:00–00:10 — Three entrances**: show the README badges and point to Web, MCP, and Codex Skill.
2. **00:10–00:25 — Create a novel**: enter a fictional premise and let the staged planner generate world, rules, style, volumes, and opening chapters.
3. **00:25–00:45 — Generate safely**: run one chapter, show the brief → plan → draft → quality pipeline and the runtime panel.
4. **00:45–01:05 — Continuity**: open characters, timeline, facts, foreshadowing, and the review queue; show that conflicts pause instead of silently entering canon.
5. **01:05–01:20 — Provider switch**: show `.env` changing from local LM Studio to an OpenAI-compatible API without changing the writing workflow.
6. **01:20–01:30 — Ship**: export Markdown/Word/EPUB/ZIP and point to CI, Docker, and the Codex Skill.

Record with a disposable test novel only. Never include API keys, personal drafts, local paths, or private logs in the recording.
